# Validation: Fastify skeleton

The work can be merged when all of the following hold.

## Must pass

- [ ] `npm run build` completes with no TypeScript errors under `strict` mode.

## Also check before merging

- [ ] `npm start` serves the "Hello AgentClinic" page at http://localhost:3000 with HTTP 200.
- [ ] Express no longer appears in `package.json` or `src/`.
- [ ] Phase 1 is ticked off in `specs/roadmap.md`.

## Not required in this phase

Automated tests (Phase 2), configuration (Phase 3) and styling (Phase 4).
